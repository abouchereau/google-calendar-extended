Installer l'application

Pour accéder plus facilement à l’application, vous pouvez l’installer sur votre écran d’accueil.

@if (isIOs) {
IPhone
  1. Appuyez sur le bouton Partager (le carré avec la flèche ⬆️)
  2. Faites défiler puis choisissez “Ajouter à l’écran d’accueil”
  3. Validez
} @else if (isChromiumBased) {
Chrome
  1. Appuyez sur le bouton en haut à droite du navigateur
  2. Choisissez “Enregistrer et partager”
  3. Choisissez “Installer Dates Saugrenue”
  4. Validez
}

Une fois installée, l’application apparaîtra comme une app classique sur votre téléphone.

@if (!isChromiumBased) {

Pour installer l'application, il est préférable d'utiliser un navigateur Chrome (ou un autre navigateur basé sur Chromium)

}
